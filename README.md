# Zami - Zamów mnie

## Overview

"Zami - Zamów mnie" is a simple and intuitive application designed for quick fast food orders. Developed as a part of the final project for the Computer Science program at Wrocław Academy of Business.

## Features

- **Easy Ordering**: Quickly place orders for your favorite fast food.
- **User-Friendly Interface**: Simple and intuitive design for a seamless user experience.
- **Secure Registration**: Register with confidence, knowing your data is handled securely.
- **Google Pay Integration**: Conveniently make payments using Google Pay.
- **PDF Invoice Generation**: Generate and view invoices for your orders.
- **Firebase Integration**: Utilizes Firebase for efficient data storage.

## Installation

To install and run the application, follow these steps:

1. Clone the repository.
   ```bash
   git clone https://github.com/YehorUd/Zami.git
   ```
2. Navigate to the project directory.
   ```bash
   cd Zami
   flutter pub get
   ```
3. Run the application:
   ```bash
   flutter run
   ```
## Usage

1. Launch the app on your device or emulator.
2. Register for an account or log in if you already have one.
3. Explore the menu and place your order.
4. Enjoy your fast food!
